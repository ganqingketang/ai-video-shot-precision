# AI 视频精准镜头翻译

把你已经想好的关键帧、剧情、人物关系、情绪和镜头感觉，转化为经过两次确认的导演方案，再翻译成视频模型更容易执行的具体提示词。

这个 Skill 不替代你的审美，也不从零替你决定创意。它是一座桥：把创作者脑海中的画面，转译成表演、调度、摄影、光影和时间都更明确的生成指令，减少模型自行发挥造成的无效抽卡。

## 适合谁

- 已经生成关键帧，但图生视频总差一点的创作者。
- 脑海中画面明确，却不熟悉导演术语或提示词语言的人。
- 需要批量生产并减少返工的 AI 视频团队。
- 能判断剧情、情绪和镜头方向，但希望提升执行精度的人。

## 不适合谁

- 完全没有情节、人物情绪或表演尺度，需要 AI 从零决定一切的人。
- 不愿意确认关键帧、镜头意图和导演方案的人。
- 期待任何模型、任何复杂镜头都保证固定生成次数的人。

## 它如何工作

1. 询问是否有关键帧；用文字明确它是位置参考、空间关系参考还是成片必须出现的硬性画面，并收集人物左右、前中后景和身体朝向。
2. 确认情节发生环境和整条视频的画面风格；不要求用户把参考图上传给 Skill。
3. 只要涉及人物表演，就请用户用大白话说明每个人物或阶段希望演得多明显；不提供固定选项，也不替用户默认夸张或克制。
4. 请用户确认 Skill 对创作意图、表演风格与幅度、环境和光源假设的理解。
5. 从导演视角补全表演、调度、构图、镜头角度、符合环境逻辑的光影和台词方案，并在展示前自查景别能否容纳所写人物、身体和道具，以及具体表演是否被放大或缩小。
6. 再次请用户确认，不擅自改变原设计。
7. 将全部分镜合并成一条按叙事时机和动作因果组织、可见、具体的视频模型提示词。
8. 失败时只修补一个明确变量，保留已经成功的部分。

第一步不询问视频模型、版本、模式、关键帧秒数或视频总时长。用户主动提供平台信息时可以利用，但不是进入流程的条件。最终无论包含多少镜头，都只交付一条提示词，正文硬性不超过 5000 字。

用户不需要会说专业术语，只要用大白话说明“人物在画面左边还是右边、离镜头近还是远、身体面向哪边”。如果没有关键帧，说明“没有”即可，Skill 会在导演方案阶段自行设计。

表演幅度也不需要专业术语。用户只需用自己的感觉说明想演得多明显；Skill 会保留这句抽象描述，并把它翻译成动作大小、速度、停顿、视线、呼吸和声音变化。情绪与幅度分开确认：“委屈”说明演什么，“比较轻微”才说明演到什么程度。

仓库内置字符检查脚本；无法运行脚本的 AI 应把提示词压到 4500 字以内，为平台计数差异留出余量。

## 安装

把下面这个 Skill 文件夹的 GitHub 链接复制给支持从 GitHub 安装 Skill 的 AI 应用：

```text
https://github.com/ganqingketang/ai-video-shot-precision/tree/main/skills/ai-video-shot-precision
```

在 Codex 中可以输入：

```text
$skill-installer install https://github.com/ganqingketang/ai-video-shot-precision/tree/main/skills/ai-video-shot-precision
```

安装后若没有显示，请重启 Codex。

## 使用示例

```text
$ai-video-shot-precision

我会在 Seedance 2.5 中使用男生和女生的角色建模参考，以及一张两人面对面的空间关系参考。你不需要读取这些图片，只需依据我的文字描述：两人面对面，女生像刚听到分手。
双人参考不是视频起始帧，也不要求复刻整张构图。
情节发生环境：日落时分的一条空旷街道，街道两侧有梧桐树；环境参考图会直接给 Seedance 2.5。
整条视频画面风格：真人实拍电影质感，日剧小清新的青春生活感。请把风格拆成可执行的摄影、光影、肤色、表演和调色规则，不要只复述标签。
女生先说“好”，转身时眼泪落下来；她快速擦掉，再转身面对男生，彻底控制不住地哭着说：“我们再试一次好不好。”
男生始终只心疼地看着她，不说话。
请先复述并确认我的设计，再给导演方案；我确认方案后，再生成最终提示词。
```

完整示例见 [分手后请求再试一次](examples/breakup-please-try-again.md)。

完成两道确认门后的单条多镜头提示词见 [最终提示词样本](examples/breakup-please-try-again-seedance-2-5.md)。

## 关于“抽卡两次以内”

这是当前希望验证的产品目标，不是无条件保证。仓库提供了一套可复现的测试口径，用首抽可用率、平均抽卡次数和两抽内成功率记录结果。公开宣传前应写明模型、版本、样本量、镜头难度和测试方式。

测试规范见 [测试计划](tests/acceptance-plan.md)。
