# 导演方案规范

## 从关系压力开始

先回答：谁在看谁、谁掌握更多信息、谁想靠近或离开、谁控制空间、观众站在哪一方。构图和机位必须由这些关系产生，而不是套用“特写更有情绪”之类模板。

为每个镜头写一句功能：

> 这个镜头让观众通过【可见关系】感受到【用户锁定的情绪或变化】。

## 先锁定表演标尺

情绪回答“人物感受什么”，表演风格与幅度回答“观众能看见多少、动作做到多大”。凡是需要设计表情、台词状态、反应或身体动作，必须先读取用户已经确认的表演风格原词；缺失时回到第一次确认门，不能由导演方案默认。

在方案开头建立简短表演标尺：

- 全场统一时，记录一条用户原词和总体边界。
- 不同人物或不同阶段尺度不同时，分别记录“人物 / 阶段—用户原词—外显边界”。
- 不把“比较夸张、比较收敛、比较轻微”做成固定数值或标准动作包；同一词在真人实拍、二维动画、喜剧或悲剧中的具体幅度可以不同，必须结合用户已锁定的画面风格和情境转译。

保留两层语言：先写用户原词作为意图标尺，再写动作大小、速度、持续时间、反应延迟、面部参与区域和声音变化。用户说“比较轻微”时，不能只剩“眼睑收紧两度”之类机械动作；用户说“比较夸张”时，也不能脱离角色与空间逻辑堆叠所有表情通道。

## 表演转译

不要列出所有微表情。根据情绪机制选择少量互相兼容的生理表现。

观察通道：

- 眼睛：眼睑张力、眨眼频率、泪膜变化、视线落点、回避速度。
- 眉额：眉间收紧或释放、额头是否参与，不把表情做满。
- 口腔：嘴角、唇缝、抿唇、下颌咬合、吞咽、呼吸是否打断台词。
- 手部：抓握、放松、擦拭、隐藏、悬停、触碰后撤回。
- 躯干：肩颈、胸腔、重心、身体朝向、步幅和停顿。
- 时间：反应延迟、动作被压回、未完成动作、事后补偿动作。

用“刺激 → 生理反应 → 主动压制 → 泄露动作 → 恢复伪装”的链条设计克制表演。不是每个镜头都需要完整链条。

例：

> 抽象意图：她委屈，但不允许自己在对方面前哭。
>
> 可见事实：她仍把下巴保持在原高度；泪膜先在下眼睑形成，眨眼被延迟；嘴唇闭紧后出现一次很小的横向颤动；她用手背快速擦过内眼角，手立即回到身体侧面；随后抬头约十度完成一次深吸气，再低头从画面右侧前景出画。动作短、快，像在抹除刚才的失控。

此例只能作为转译粒度参考，不能成为所有“委屈”场景的固定表演模板。

每个情绪节拍只选择与已确认幅度相符的观察通道。表演偏轻微或收敛时，减少同时参与的面部和身体区域，缩短动作、控制位移与声音变化；表演偏明显或夸张时，可以扩大动作范围、延长反应或增加躯干参与，但仍要服从人物关系、景别容量和画面风格。不能把“细节写得多”误当成“表演更准确”。

## 场面调度

为人物和摄影机分别写轨迹：

- 初始坐标：左 / 中 / 右，前 / 中 / 后景，朝向和距离。
- 触发事件：一句台词、视线相遇、另一人动作或环境变化。
- 移动路径：朝屏幕哪个方向、靠近或远离摄影机、经过谁的前景或阴影。
- 停止条件：停在物体、光区、人物或构图边界的什么位置。
- 结束状态：是否入画、留画、被遮挡或从哪一层出画。

避免“走过去”“从另一边离开”“镜头跟着她”这类没有屏幕方向、层次和停止点的描述。

## 摄影方案

至少明确：

- 景别与主体占画比例。
- 机位高度、俯仰角和观看立场。
- 焦段倾向及其叙事作用，不为参数而参数。
- 主体位于画面什么位置，谁或什么形成前景压力。
- 摄影机静止或运动；运动的起点、方向、速度、幅度、触发点和停止点。
- 焦点开始在哪里，是否以及何时转移。
- 画面轴线与人物屏幕方向。

摄影机运动只能承担一个主要任务：揭示、靠近、疏离、跟随、阻断或转移注意力。不要在同一短镜头里同时推、摇、环绕、变焦和跟焦。

### 景别与可见元素的几何边界

景别不是气氛标签，而是对画面能容纳什么的硬约束。为每个镜头先列出“可见元素清单”和“不得入画清单”，再写表演与道具。

| 景别 | 通常允许出现 | 通常不能出现 |
|---|---|---|
| 纯面部特写 | 脸、极少量头发、抽象或失焦背景 | 肩膀、胸口、手、桌面、桌面道具、第二人物 |
| 头肩特写 | 头、肩部少量区域、画外视线 | 腰部动作、桌面道具、完整手部调度、第二人物，除非明确改为双人特写 |
| 中近景 | 头部至胸 / 腰附近，可容纳靠近身体的手部和少量桌沿 | 远离身体或位于低处的道具，除非机位角度能解释 |
| 中景 / 全景 | 人物身体、站坐关系、桌椅、人物间距、完整手部调度 | 与镜头位置和遮挡关系不相容的细小表情细节 |
| 道具特写 | 单一道具、接触它的必要手部、少量相邻表面 | 同时清楚展示远处人物完整面部反应 |

这是默认几何规则。只有用户明确要求特殊构图，且机位、焦段、俯仰角与焦平面可以物理解释时才能例外；例外时不要继续把镜头称为“纯面部特写”。

单人镜头只能出现一名可辨认人物。角色可以把视线投向另一个人，但另一人必须写成“位于画外左侧 / 右侧”，不能用“看着某人”造成第二主体似乎也在画内的歧义。若用户要求“画面里只有她的脸”，除脸、极少量头发和背景色块外，删除所有身体、手、桌面、日记和其他人物。

道具与人物面部不在同一取景范围时，不得为了交代信息把道具塞进前景。需要同时表达“看到道具”和“人物反应”时，选择一种：

- 改为能容纳两者的中近景，并明确机位与焦点转移。
- 先拍道具特写，再切人物反应特写。
- 保持纯面部特写，只通过视线和表情暗示画外道具。

### 镜头角度是必填设计项

用户没有给角度时不必追问，但导演方案必须主动选择并写明：

- 摄影机高度：高于、平于或低于主体视线。
- 俯仰关系：俯拍、平拍或仰拍。
- 水平位置：正面、三分之二侧面、正侧面或背侧。
- 关系作用：亲近、疏离、压迫、被观察、掌握主动或隐藏信息。

角度必须服务当前关系，不能只写“电影感角度”。例如，坐姿人物视线高度的平拍可让站立俯身者自然占据空间优势；轻微俯拍害羞人物可以强化退缩，但不能把人物贬低成喜剧对象。

### 方案展示前的内部校对

每个镜头在展示给用户前，逐项检查：

1. 镜头名称写了几名主体，实际画面是否出现了相同数量的可辨认人物？
2. 景别能否容纳所写的脸、肩、手、桌面、道具和背景？
3. 前景、中景、后景和焦平面是否能由同一个摄影机位置成立？
4. 人物视线指向画内还是画外，文字是否明确？
5. 机位高度、角度和观看立场是否已经写明，并服务人物关系？
6. 道具的移动方向和人物手部是否在当前景别中可见且不会穿帮？
7. 上一镜结束构图能否自然接到下一镜，而不让人物、道具或摄影机瞬移？
8. 每个人物或阶段的具体动作、声音和反应时差，是否匹配用户确认的表演风格原词；是否无意中把轻微演成明显，或把夸张压成没有反应？

发现基础矛盾必须先修改方案，不得依赖第二次确认让用户代替 Skill 找错。

## 环境、风格与光影综合判断

先结合四项信息：情节功能、发生环境、画面风格、用户已锁定的视觉事实。不要先套“冷色悲伤”“暖色治愈”等情绪滤镜。

### 环境事实

从用户给出的地点推导可存在的空间结构和光源，但不要捏造会改变情节的物件：

- 教室可能有侧窗、顶灯、走廊门和黑板反射；采用哪一种取决于白天 / 夜晚、情绪和风格。
- 操场白天主要来自太阳和天空；夜晚主要来自球场灯、路灯、建筑窗光或看台设施。
- 卧室可以由窗、床头灯、顶灯、门缝或屏幕照明，但不能同时无理由出现多组强主光。
- 地铁站的光来自顶棚灯箱、列车窗、站台屏幕和隧道，不应出现无法定位的巨大柔光箱效果。

用户只给地点时，选择一套最能服务剧情且物理合理的时间、天气和光源组合，并在第一次确认中明确说明这是一项待批准的创作加法。

### 画面风格适配

- **真人实拍电影**：使用真实摄影机位置、镜头尺度、自然皮肤与材质、实际光源、可信曝光和光学限制。
- **日剧小清新式青春生活感**：在真人实拍规则上，使用自然肤色、真实皮肤纹理、柔和但不过度奶油化的高光、干净的低至中等反差、适度降低的饱和度、安静留白、克制的生活化表演和轻缓摄影机运动；避免商业广告式美颜、重度青橙调色、过量柔光光晕和为了“唯美”添加的无来源逆光。
- **CG 动画**：保持空间与光源逻辑，明确材质响应、体积、景深、角色运动曲线和渲染质感；不要默认塑料皮肤、游戏宣传片打光或无来源轮廓光。
- **二维手绘动画**：把风格落实为线条粗细与稳定度、角色造型概括、背景绘制介质、色块与赛璐璐层次、阴影形状、帧间运动和景深分层；不强行加入真人镜头的皮肤、胶片颗粒或物理材质要求。
- **具体创作者或作品风格**：提取并描述高级视觉特征，例如手绘线条、自然题材、柔和色块、水彩背景、克制的二维阴影和生活化动作；不要把最终提示词仅写成创作者姓名，也不要复刻标志性角色、构图或具体作品。

风格不改变剧情锁定项，但会改变人物动作的夸张程度、光影表现、材质、综合色、背景细节、摄影或虚拟摄影方式。

### 光源逻辑

光影必须有来源，并服务人物关系：

- 主光来自窗、顶灯、台灯、路灯、门外、火光或其他实际来源。
- 写清人物开始处于亮区、半影还是暗区。
- 写清人物动作如何改变受光，而不是让灯光无原因追随情绪。
- 可让强势人物的身体或空间结构投下阴影，但必须符合光源方向。
- 抽象色彩感觉要落到环境、服装、光源色温和反射表面。

强制检查：

- 夜间室外的大面积暖光必须能追溯到夕阳余光、路灯、店铺、火焰、车灯或其他场景内来源；否则改为更合理的月光 / 天空环境光与局部实际光。
- 室内的大面积高亮或过曝必须来自可见或可推断的窗、门、灯具、屏幕或反射面；不能凭空让背景或人物轮廓爆亮。
- 太阳、窗光、灯具和人物投影的方向必须一致；人物移动到另一光区时才改变受光关系。
- 动画允许简化或夸张光影形状，但光源方向和世界观规则仍要前后一致。
- 不为了“高级感”同时堆叠逆光、顶光、轮廓光、体积光和大面积雾气。

## 台词表演

不要只写“悲伤地说”。说明：

- 音量与气息。
- 语速与停顿位置。
- 哪个词被压低、咬紧、吞掉或失去尾音。
- 台词前、中、后分别发生什么身体动作。
- 人物是否看向对方；若回避，视线落在哪里。

## 单次生成中的镜头预算

不要要求用户提供秒数。多个独立叙事事件应分配到同一条最终提示词里的不同镜头，而不是拆成多次生成。每个镜头保留一个主要叙事动作和少量属于同一生理链条的微动作，并写清镜头之间的动作接点。

出现以下情况时，在导演方案中增加切镜，但最终仍合并为一次生成：

- 两名以上人物分别完成复杂动作。
- 人物大幅移动，同时摄影机需要改变观看立场。
- 同一人物连续完成方向相反的动作。
- 关键帧构图与下一情绪节点需要不同景别。
- 道具发生复杂接触、交换、变形或遮挡。

优先使用动作匹配切、遮挡切、视线切、声音先行或停顿后切。除非用户明确要求分开，否则不得把镜头拆成多条提示词或建议逐镜头生成。

## 多镜头连续性

建立连续性账本：服装、发型、手持物、人物左右关系、视线方向、动作接点、光源方向、时间、天气、镜头轴线和上一镜结束姿态。每个镜头只读取自己需要的状态，同时检查与相邻镜头的入口和出口。

## 第二次确认的用户检查提示

通过内部校对后，再提醒用户从创作意图层检查：

- 分镜数量、顺序和切点是否符合脑海中的节奏。
- 景别和镜头角度是否符合观看立场。
- 人物站位、动作和表演是否符合角色。
- 情绪变化、台词尺度和留白是否准确；抽象表演风格是否被翻译得过大或过小。
- Skill 新增的视听语言是否有不希望保留的部分。

这些是创作选择，不等于把主体数量、景别几何或焦平面错误交给用户检查。
