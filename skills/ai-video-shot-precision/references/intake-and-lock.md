# 需求锁定与确认

## 输入账本

| 类别 | 记录内容 |
|---|---|
| 情节环境 | 地点；已知的时间、天气、季节、窗户、门、灯具和其他可见光源 |
| 整片画面风格 | 真人实拍电影、CG 动画、二维手绘动画或具体可见风格 |
| 参考信息 | 用户将交给视频模型的角色、服装、环境、空间、构图、起始帧或结束帧参考；只需文字描述用途并标注软 / 硬约束 |
| 关键帧用途 | 位置参考、空间关系参考，或最终视频必须出现的硬性画面 |
| 方位锚点 | 主体位于画面左 / 中 / 右哪个范围；前 / 中 / 后景；身体和脸朝向哪里 |
| 情节顺序 | 整场戏的前因、事件顺序、转折与结束状态 |
| 叙事时机 | 关键帧发生在什么事件之前 / 之后 / 同时；它是动作起点、转折、反应还是结果 |
| 关键帧 | 人物、姿态、表情、视线、手部、道具、空间、构图和光线 |
| 人物关系 | 权力、亲密度、距离、秘密、彼此知情程度 |
| 情绪 | 主情绪、次情绪、隐藏情绪、外显程度和变化节点 |
| 表演风格与幅度 | 用户对每个人物或情绪阶段给出的抽象感觉原词；例如偏夸张、偏收敛、非常轻微，但不把这些写成供用户选择的固定档位 |
| 用户已有设计 | 动作、分镜、调度、摄影、光影、台词、声音和抽象感觉 |
| 锁定项 | 必须原样保留，不得重写 |
| 允许润色 | 可以增加细节但不能改变方向 |
| 禁止项 | 不能出现的动作、表情、运镜、物体或剧情 |
| 待确认 | 存在多种解释且会改变画面的内容 |

不把模型、版本、模式、提示词语言、总时长、帧率或关键帧秒数列为第一步输入，也不主动询问。用户主动给出时可以记录为背景信息，但不能因此改变两道确认门和单条提示词交付。

## 最少提问原则

只问会改变最终画面的信息，优先一次集中询问：

1. 有关键帧吗？不需要上传，用大白话描述即可。若有，它只用于位置、用于空间关系，还是最终视频里必须出现的一帧？
2. 关键帧中主体大概在画面左、中、右哪个范围，处于前景、中景还是后景，身体和脸朝向哪里？
3. 关键帧大概发生在哪个情节、台词、动作或情绪变化之前 / 之后？
4. 人物真实感受什么，试图让别人看到什么？
5. 这几个人物分别希望演成什么感觉，动作和情绪需要表现得多明显？请用户用自己的大白话描述，不提供固定选项，也不要求微表情术语。
6. 哪些内容绝对不能重新设计？已经确定了哪些镜头、构图、动作或运镜？
7. 整个情节发生在什么环境，整条视频是什么画面风格？

不要询问使用什么模型，也不要询问关键帧在第几秒、视频一共几秒。用户明确没有关键帧时，不再反复追问，由导演方案根据已锁定情节自行设计。用户只给地点时，可结合剧情与风格提出物理合理的时间、天气和光源假设，放入第一次确认。

情绪词不能代替表演幅度。用户说“她很委屈”时，仍需知道希望这种委屈演得多明显；用户已经主动说“只小幅度抽泣、整体非常收敛”时，不重复询问，直接把原词写入账本并在第一次确认中复述。全场表演风格一致时可以锁定一条全局尺度；人物之间或前后阶段明显不同，则分别记录。不得用题材、人物性格、真人 / 动画风格替用户推断表演幅度。

## 参考信息约束分级

- **身份参考**：保持人物身份特征，不默认复制姿势、机位或背景。
- **空间关系参考**：理解人物距离、朝向、左右关系或场景布局；除非用户锁定，不逐像素复刻构图。
- **构图参考**：保持主要画面关系，但允许在用户许可范围内调整表演和摄影机。
- **起始帧 / 结束帧**：属于硬锚点，动作必须从该状态出发或落到该状态。
- **智能参考或软参考**：只提取用户点名的维度，不把整张图升级成硬性关键帧。

## 关键帧用途判定

- **位置参考**：只锁定主体在画面左 / 中 / 右及前 / 中 / 后景的位置，不锁定完整构图、机位、动作或光线。
- **空间关系参考**：锁定人物之间、人物与桌椅 / 门窗 / 环境之间的距离、朝向和遮挡关系，不自动要求该画面在成片中逐帧复现。
- **必须出现的硬性画面**：最终镜头序列必须通过合理动作到达该画面；景别、主体数量、姿态、视线和关键道具不能被改写。

用户说“关键帧”但没有说明用途时必须追问，不能自行替用户选择。用户没有提关键帧时，询问一次是否有可用的文字描述；确认没有后才自由设计。

方位问题使用大白话，例如：“人物大概在画面左边还是右边？离镜头近还是远？身体面向谁或哪一边？”可以在记录时转成专业术语，但不要要求用户先会说“前景、三分构图、三分之二侧身”等词。

当前 AI 不需要读取图片；依据用户的文字描述工作。文字不足时只追问会影响剧情、空间、人物动作或光源逻辑的可见事实。

## 冲突检测

- 关键帧姿态是否允许前后动作自然衔接？
- 表演是否与人物关系和台词情绪冲突？
- 具体表情、动作、声音和反应时差是否与用户确认的表演风格与幅度一致，是否在方案中被无意放大或削弱？
- 人物运动是否与镜头轴线和相邻镜头方向冲突？
- 镜头切换是否有动作、遮挡、视线、声音或叙事触发？
- 光源方向、色温、强度、投影和曝光是否与环境相容？
- 全部镜头能否按因果顺序写入同一条提示词，而不产生主语和动作归属歧义？
- 关键帧用途是否明确，方位锚点是否足以避免人物左右、景层和身体朝向漂移？

发现冲突时输出冲突点、失败原因和保留用户意图的兼容方案，不擅自选择。

## 第一次确认模板

```markdown
## 我先冻结你的创作意图

- 情节与人物关系：
- 主情绪 / 隐藏情绪：
- 各人物或阶段的表演风格与幅度（保留用户原词）：
- 关键帧及叙事时机：
- 关键帧用途与方位锚点：
- 情节环境与整片风格：
- 实际光源假设：
- 已有镜头设计：
- 必须保留：
- 禁止新增：
- 我仍需确认：

以上理解是否准确？你确认后，我再做完整导演方案。
```

## 第二次确认模板

```markdown
## 导演方案确认

### 保留的设计
- ...

### 只做的加法
- ...

### 完整镜头序列
- 镜头一：...
- 镜头二：...

### 连续性与风险
- ...

### 请用户重点检查
- 分镜数量和顺序是否符合脑海中的画面？
- 景别、镜头角度和人物站位是否准确？
- 人物表演、情绪变化与表演尺度是否准确？
- 用户给出的抽象表演风格是否被翻译得过大或过小？
- Skill 增加的镜头语言是否有不符合创作意图之处？

如果这版准确，请回复“确认方案”；确认后我把全部镜头合并成一条不超过 5000 字的最终提示词。
```
