# 提示词翻译规范

## 最终交付形态

最终交付必须是一条完整提示词，而不是多条逐镜头提示词。多个镜头使用同一提示词内部的“镜头一、镜头二……”组织，由视频模型一次生成整场戏。

最终提示词正文硬性不超过 5000 个 Unicode 字符，标点、空格和换行也计入。常规目标控制在 4500 字以内，为不同平台计数方式保留余量。除提示词代码块外，只允许报告字符数，不再提供第二版、负面词副本或逐镜头复制块。

## 单条多镜头结构

按以下顺序写进同一个代码块：

```text
【整体与参考】画幅、参考素材用途、环境、风格、人物关系、综合色和全片连续性。

【镜头一】起始构图；人物初始状态；触发事件；主要表演和调度；摄影机；台词或声音；结束动作与下个镜头切点。

【镜头二】承接上一镜的动作、视线、遮挡或声音；新的主要动作；摄影机；结束状态。

【后续镜头】按同样方式继续，直到用户要求的整场戏完成。

【全片连续性】身份、服装、发型、左右关系、轴线、视线、道具、环境、光源、天气、综合色和声音保持规则。

【禁止】只列与当前场景高风险失败直接相关的限制。
```

镜头标题只是同一提示词中的结构标记，不能被拆成不同代码块或不同生成任务。

## 翻译原则

同时保留两层：

1. **意图层**：用户原始的情绪、氛围、关系和审美词。
2. **执行层**：可见姿态、表情变化、屏幕方向、空间层次、摄影机、环境、光源、声音和动作节点。

不得用执行层删除意图层，也不得只保留意图层。

人物表演同样保留双层：先写用户确认的表演风格与幅度原词，再写对应的表情、动作、声音和反应时差。全场尺度一致时可在开头统一声明；人物或阶段尺度不同，则在相应人物或镜头中分别注明。不得把“比较轻微、比较收敛、比较夸张”等原词压缩掉，也不得用一组具体动作悄悄改变其幅度。

## 动作与切镜

- 用“说完这句后、转身时、擦泪后、再次面对对方前”等相对叙事时机定位，不要求时间码。
- 每个镜头优先承担一个主要叙事动作；多个独立事件分配到同一提示词内的不同镜头，而不是拆成多次生成。
- 写清镜头之间如何连接：动作匹配切、人物遮挡切、视线切、声音先行或停顿后切。没有触发理由的突然切镜应删除。
- 写清上一镜结束姿态如何成为下一镜起始状态，不让模型自行补中间因果。
- 人物、摄影机、焦点、环境和声音分别使用清楚主语。
- 多人物始终使用角色名、服装标识或画面位置，避免连续使用含糊代词。
- 写清屏幕左 / 右、前景 / 中景 / 后景、面向或背离谁，以及出入画方向。
- 纯面部特写只写脸、极少量头发和背景；不得在翻译阶段重新加入手、肩、桌面、日记或第二人物。
- 单人镜头的视线写成“看向画外左侧 / 右侧”，不要写成可能让模型误判另一人物也在画中的“看着某人”。
- 道具与面部不在同一取景平面时，不能用“前景道具 + 纯面部特写”强行合并；应沿用已确认的中近景、道具特写或画外视线方案。

## 可见语言

| 含糊表达 | 可执行方向 |
|---|---|
| 他很忧伤 | 下眼睑张力、视线落点、呼吸、下颌、反应延迟和动作幅度 |
| 她想哭但忍住 | 泪膜变化、眨眼延迟、抿唇、吞咽、压制动作和恢复伪装 |
| 他走到另一边 | 从当前画面位置沿明确路径移动到屏幕左 / 右侧的前 / 中 / 后景 |
| 镜头慢慢靠近 | 从何景别、因何触发、以何速度运动并在何景别停止 |
| 光变暗了 | 人物因转身或移动离开哪个实际光区，面部哪一侧进入半影 |
| 很高级 | 材质、色谱、光源数量、构图留白、摄影机克制和表演尺度 |

不要机械套用表格。只选择服务当前情节的细节。

## 风格语言

- 真人实拍使用摄影机位置、焦段倾向、景别、景深、实际光源、曝光、皮肤和材质语言。
- CG 动画使用虚拟摄影机、材质响应、角色运动曲线、渲染光源和空间体积语言。
- 二维动画使用线条、色块、赛璐璐阴影、背景绘制、层间视差、动作帧和形变节奏语言。
- 用户以具体创作者或作品描述风格时，提炼为可见特征，不把姓名当作唯一指令，不复制标志性角色或具体镜头。

## 5000 字压缩优先级

超长时按照以下顺序压缩，不能删除锁定项：

1. 删除导演解释、创作理由和重复的情绪形容词。
2. 合并跨镜头重复的环境、风格、参考身份和光源说明，统一放在开头或连续性段。
3. 删除不能改变生成结果的焦段数字、程度副词和同义词，只保留有功能的参数。
4. 合并重复禁止项，改为一次全片约束。
5. 把同一生理链条的微动作合并成短句，但保留触发、主要动作和结束状态。
6. 精简低风险背景细节和声音修饰。

不得为了压缩删除：台词原文、关键动作顺序、关键帧叙事时机、人物关系、用户锁定镜头、核心表演尺度、屏幕方向、镜头切点、光源方向和关键禁止项。

使用 `scripts/check_prompt_length.py` 时，把最终代码块正文作为文件或标准输入传入。若无法运行脚本，正文控制在 4500 字以内。

## 负面限制

负面限制必须位于同一条提示词末尾，少而具体：

- 不新增人物、道具或剧情事件。
- 不改变身份、服装、发型、面部和空间布局。
- 不反转人物屏幕方向或轴线。
- 不增加未经批准的台词、表情、接触、离开或结局。
- 不出现与环境不符的无来源光、投影和曝光变化。
- 仅在手部、接触或多人遮挡确为本场风险时，增加相应穿帮限制。

## 翻译后的几何复核

字符压缩完成后再次检查，避免压缩或改写重新制造矛盾：

- 每个镜头的景别名称与可见元素一致。
- 单人镜头没有第二名可辨认人物；画外视线明确标注“画外”。
- 纯面部特写没有肩膀、手、桌面或道具。
- 机位高度、俯仰角和正面 / 侧面关系没有被压缩掉。
- 前中后景、焦点和景深能由同一个摄影机位置成立。
- 关键帧按已确认用途执行：软参考没有被升级，硬性画面没有被遗漏。
- 用户确认的表演风格与幅度原词仍在，具体表情、动作、声音和反应时差没有把它放大或缩小。

## 单变量修订

第一次生成失败后，先归类失败原因。只改变造成失败的最小镜头片段，其余文字保持不变；再次交付时仍输出一条完整替换提示词，不能让用户额外拼接补丁，且仍须通过 5000 字检查。用户反馈“演得太夸张 / 太小”时，把它归类为表演幅度变量，只缩放相关人物或阶段的动作范围、参与部位、速度、持续时间、声音和反应延迟，不同时重写构图、调度、光影或剧情。
